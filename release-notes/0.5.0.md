# OZ Rewards 0.5.0

- First sector discoverers are recorded immediately; destination-region announcements follow the configured delay.
- Kill payouts move to a world-specific JSON catalog with an in-game administrator editor and a dedicated menu icon.

On first startup, the catalog is seeded from the effective legacy kill values. Keep the existing world settings and data when updating.

Requires Java 25 and the current Rising World PluginAPI.
